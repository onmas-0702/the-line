# 은혜의 밤 더 라인 — 와이어프레임

목회자 오디오 나눔 플랫폼의 와이어프레임입니다. Next.js(App Router) + Tailwind CSS로 만들었고,
실제 인증/DB 연동 없이 화면 흐름과 레이아웃만 확인할 수 있는 목업 데이터로 구성되어 있습니다.
데이터는 브라우저 localStorage에 저장되어, 새로고침해도 방금 만든 오디오/노트가 유지됩니다
(다른 브라우저·기기에는 공유되지 않는 로컬 미리보기용 저장소입니다).

기존에 진행 중인 `onmas` 프로젝트와는 별개의 신규 프로젝트입니다.

## 포함된 화면 및 기능

- `/` 홈 피드 — 전체 오디오 목록, 정렬(최신/인기/제목), 표시 개수 설정, 영감노트 태그,
  다른 목사님 오디오를 "마이페이지에 담기"
- `/login` — Google / 카카오 로그인 버튼 (실제 인증 미연결)
- `/record` — 녹음(마이크 입력장치 선택, USB 마이크 포함) 또는 파일 업로드 →
  파형 기반 마그네틱 타임라인 편집(자르기, 클립 드래그 이동, 구간 삭제 → 빈 공간 →
  빈 공간 삭제 시 자석처럼 자동 이어붙이기, 재생/탐색), 배경음악은 공식 라이브러리(읽기 전용) /
  내 라이브러리(업로드·삭제 가능) 두 곳으로 분리, 볼륨 조절, 제목/분류, 대본 첨부
- `/notes` — 영감노트 빠른 작성(첫 줄 자동 제목), 정렬, 표시 개수 설정, 연결된 오디오 표시
- `/mypage` — 내 오디오(직접 만든 것 + 담아온 것) 분류/필터, 정렬, 표시 개수 설정, 삭제,
  오디오/대본 다운로드 버튼, 오디오별 영감노트 인라인 작성·조회

## 로컬에서 확인하기

1. Node.js 18.18 이상이 설치되어 있어야 합니다 (`node -v`로 확인).
2. 이 폴더에서 의존성을 설치합니다.

   ```bash
   npm install
   ```

3. 개발 서버를 실행합니다.

   ```bash
   npm run dev
   ```

4. 브라우저에서 http://localhost:3000 접속.

내용을 새로 확인하고 싶다면 브라우저 개발자도구 콘솔에서
`localStorage.removeItem("eunhye-the-line-store-v1")` 후 새로고침하면 초기 목업 데이터로 리셋됩니다.
